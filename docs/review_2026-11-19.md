# Pre-results adversarial review (2026-11-19)

Before any external (UCDDB) number was computed, five independent reviewers
examined the pipeline through separate lenses (leakage, label alignment,
metric definitions, feature correctness, R-peak/RR rules). An independent
skeptic then tried to refute each finding. 24 findings were confirmed and
5 were rejected. All fixes below landed before the single UCDDB run.

| # | Severity | Finding | Resolution |
|---|---|---|---|
| 1 | critical | Feature cache held no CAP rows (download incomplete); training would have run on slpdb only, with no error | `train_eval.py` aborts unless the cache holds exactly the configured records of every dataset; `build_features.py` checks every raw file first; results JSON stores the record list and feature-cache SHA-256 |
| 2 | major | CAP n16 has no ECG channel | Removed from the config (15 CAP controls remain) |
| 3 | major | Apnea-ECG c06 is the same recording as c05 (identical RR, shifted 80 s) | Both map to one subject for CV grouping and bootstrap |
| 4 | major | Apnea model and apnea-minute error not implemented | Added the `apnea` task (Apnea-ECG train, UCDDB test, OOF threshold) |
| 5 | major | Robust z-score fell back to scale 1.0 for degenerate features (all-zero pNN50), only on test records | Scale chain IQR -> 1.4826 MAD -> SD -> 1, z clipped to +-10 |
| 6 | minor | Final GB model used sklearn's automatic early stopping (random, non-grouped split); fold models did not | `early_stopping = false` in the config |
| 7 | minor | Internal-CV bootstrap resampled records, not subjects | Bootstrap accepts record -> subject groups |
| 8 | minor | Internal CV excluded low-quality epochs while external evaluation included them | OOF predictions now cover every labeled training epoch; thresholds and internal CV use them |
| 9 | minor | `night_fraction` depended on the scored-span length, which the demo cannot reproduce | Feature removed; only `hours_since_start` from the first grid epoch remains |
| 10 | minor | An apnea event ending exactly on a minute boundary marked the next minute | Ceil-based end minute |
| 11 | minor | Awakenings merged wake runs across dropped epochs | Runs reset at gaps in the epoch grid |
| 12 | minor | Kappa returned 1.0 when both raters used one class | Returns NaN (skipped in per-record means) |
| 13 | minor | Detector threshold purely relative: flat/lead-off stretches produced false beats | Recording-level threshold floor; no-signal blocks yield no beats |
| 14 | minor | Search-back recovered at most one beat per gap | Repeated up to 5 passes |
| 15 | minor | Cached beats were not versioned | Cache stores the SHA-256 of `rpeak.py` |
| 16 | minor | Detector validation counted reference gaps as false positives and fiducial offset as error | Reference gaps excluded; signed and offset-corrected timing errors reported |
| 17 | minor | Unused config keys (`max_gap_s`, `detector_fs_hz`) | Removed and documented |

The remaining confirmed items were duplicates of the above (raised by more than one lens).

## Accepted limitation (not changed)

- slpdb slp01a/b and slp02a/b are two segments of one night each. They are
  processed as separate records, so their per-night normalization and
  `hours_since_start` restart at the second segment. This affects 4 of 67
  training records and no test record. The pairs share a subject ID, so CV
  folds and bootstrap keep them together.
